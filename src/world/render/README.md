# World Render Pass Helpers (`src/world/render`)

## Overview
Provides specialized, stateless helper classes (`RefCounted`) that implement the delegated rendering passes for `EvoWorldRenderer`: single-deme full-hex 4-tier (`I..IV`) settlement architecture, rural hinterland (`crops`, `pasture`, `has_ruins`) and biome flora layout/sorting (`EvoPropFloraRenderer`), inter-hex roads, rural farm tracks, hex-edge perimeter fortifications, and continuous multi-hex walled unions (`EvoRoadNetworkRenderer`), and screen-space village billboards with salubrity indicators, rural territory crests, and seasonal ambient particles (`EvoWorldOverlayRenderer`).

## Invariants
- `[prop_flora_renderer.gd:collect_villages]` enforces single-deme centered settlement placement (`scale_factor == 1.0`, `HexMath.compute_village_sector_offset == Vector2.ZERO`) and clamps `villager_count` to `[3, 9]`.
- `[prop_flora_renderer.gd:get_village_building_layout]` distributes 4-tier (`I..IV`) high-DPI settlement architecture (`hut_thatch`, `house_clay`, `house_stone`, `granary`, `windmill`, `watchtower`, `temple_totem`, `citadel_keep`, `cathedral`) across the hex interior with building scales `>= 2.35 * sf`.
- `[prop_flora_renderer.gd:compute_cell_flora_key]` includes `int(cell.altitude * 100.0) * 1000 + int(cell.carrying_capacity) * 10 + cell.biome.hash() + cell.land_use.hash() * 31 + (17 if cell.has_ruins else 0)` so converting a hex to `"crops"`, `"pasture"`, or `has_ruins` immediately invalidates `_cell_flora_cache`.
- `[prop_flora_renderer.gd:collect_cell_flora_props]` suppresses interior wild trees on `"crops"` and `"pasture"` hinterland hexes to place `crop_field`/`pasture_pen`, `windmill`, and `granary` props with peripheral hedgerow trees (`0.74..0.84 * HEX_SIZE`), and renders `ruins_stone` props whenever `cell.has_ruins == true`.
- `[road_network_renderer.gd:draw_settlement_perimeter_walls]` draws 2.5D timber palisade or crenellated stone curtain walls along the 6 hex edges (`wall_r = 0.78`) of fortified/Tier 3–4 settlements, and culls the internal wall along any hex edge shared with a neighbor holding the exact same non-empty `deme.walled_union_id`, replacing it with a paved union boulevard.
- `[world_overlay_renderer.gd:draw_village_billboard]` displays the Roman settlement category (`I..IV`) alongside population and renders a color-coded salubrity indicator (`>= 0.75` emerald, `0.40..0.74` amber, `< 0.40` crimson) whenever `deme.salubrity < 0.75` or `deme.get_village_tier() >= 3`.

## Side Effects
- `[prop_flora_renderer.gd:get_villager_textures_for_color]` populates `r._villager_tex_sets` on the `EvoWorldRenderer` instance.
- `[prop_flora_renderer.gd:collect_static_props]` mutates `r._cell_flora_cache` (`__sorted_flora__`, `__flora_cam__`, and per-hex flora caches).
- `[prop_flora_renderer.gd:collect_village_building_props]` caches generated building prop arrays in `Deme` metadata (`_vp_key`, `_vp_val`).
- `[prop_flora_renderer.gd:acquire_moving_prop]` and `[prop_flora_renderer.gd:collect_moving_props]` mutate `r._moving_prop_pool` and `r._moving_prop_count`.
- `[road_network_renderer.gd:collect_roads]` sets `_v_pos_cache`, `_deme_v_cache`, and `_deme_stance_cache` metadata on `r`.
- `[world_overlay_renderer.gd:_draw_deme_billboards]` and `[world_overlay_renderer.gd:draw_village_billboard]` clear and populate `r._deme_hit_rects` for screen-space mouse hit-testing.
- Drawing methods issue `CanvasItem` draw calls to `r._network_layer`, `r._anim_layer`, and `r._overlay_layer`.
