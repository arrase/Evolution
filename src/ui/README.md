# UI Subsystem (`src/ui`)

## Overview
Implements the pixel-art parchment and wood user interface for **Evolution**, including the root HUD orchestrator (`EvoMainHud`), the centralized theme and procedural pixel-icon styling singleton (`EvoUiStyle`), and the three interactive modals: the 4-tab Strategy, Trait & Decision Forge (`EvoLabModal`), the 18-filter Naturalist's Notebook chronicle viewer (`EvoNotebookModal`), and the interactive Phylo-Cultural Lineage Tree (`EvoTreeModal`).

## Invariants
- `[main_hud.gd:_set_startup_blocked]` — Disables `_play_btn` and `_step_btn`, stops active generation playback, and blocks hotbar key input (`[main_hud.gd:_unhandled_key_input]`) whenever Ollama is offline or required decision models are missing.
- `[lab_modal.gd:_on_strategy_trait_toggled]` / `[lab_modal.gd:_build_strategy_from_form]` — Enforce mutual exclusion between `bio-r-strategy` and `bio-k-strategy` (and any `TraitDef.mutually_exclusive_with` entries) and ensure cultural traits in a strategy are always accompanied by a biological trait with `enables_cultural_transmission`.
- `[lab_modal.gd:_save_current_item]` — Enforces thermodynamic conservation via `EvoUiStyle.balance_vector` on saved traits and decisions unless `_world_state.free_sandbox_mode` is `true`.
- `[lab_modal.gd:_on_inject_pressed]` — Rejects injecting cultural traits into demes lacking cultural capacity (`EvoCatalog.deme_has_cultural_capacity`).
- `[notebook_modal.gd:_rebuild_entries]` — Displays chronicle entries newest-first and caps rendered cards at 100.

## Side Effects
- `[main_hud.gd:_on_export_pressed]` / `[main_hud.gd:_on_import_pressed]` — Read and write `user://evolution_world_state.json` via `FileAccess`.
- `[main_hud.gd:_on_primary_model_selected]`, `[main_hud.gd:_on_secondary_model_selected]`, `[main_hud.gd:_commit_context_window_text]` — Update and persist `EvoUserSettings` (`save_settings()`), clear `EvoOllamaClient` cache, and trigger `EvoDecisionModel` re-evaluation.
- `[main_hud.gd:_on_missing_models_download_pressed]` / `[main_hud.gd:_on_missing_models_skip_pressed]` — Invoke `EvoOllamaClient.start_pull_models` / `EvoOllamaClient.cancel_pull` and emit `quit_requested`.
- `[lab_modal.gd:_save_current_item]` / `[lab_modal.gd:_on_inject_pressed]` — Mutate `_world_state` catalogs/demes and persist custom user catalog items to disk via `EvoUserSettings.save_user_catalog(_world_state)`.
- `[ui_style.gd:get_theme]` / `[ui_style.gd:get_pixel_icon]` — Cache `Theme`, `StyleBoxFlat`, and `ImageTexture` instances in static caches (`_cached_theme`, `_stylebox_cache`, `_icon_cache`) and delegate sprite lookup to `EvoPixelArtGen.get_texture`.
