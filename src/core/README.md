# Core (`src/core`)

## Overview
Provides the foundational data structures (`EvoTypes`), 6-axis biophysical thermodynamic conservation laws (`EvoThermodynamics`), pointy-top axial hexagonal grid geometry (`HexMath`), base biological/cultural/strategy catalogs (`EvoCatalog`), scientific scenario world builders (`EvoPresets`), bilingual (`es`/`en`) localization (`EvoI18n`), and persistent user settings and custom catalog storage (`EvoUserSettings`).

## Interface
- `[types.gd:EvoTypes]` — Constants `BIOMES`, `ARCHETYPES`, `SPECIATION_PALETTE`, `BIOME_CLIMATE_DEFAULTS`; inner data classes `BiophysicalVector`, `TraitDef`, `DecisionDef`, `StrategyDef`, `HexCell`, `Deme`, `LineageNode`, `ChronicleEntry`, `HexEdgeFlow`, `WorldState`; static helpers `make_pair_key(id_a, id_b)`, `is_pact_active(state, id_a, id_b)`, `is_vendetta_active(state, id_a, id_b)`.
- `[thermodynamics.gd:EvoThermodynamics]` — `BASE_BUDGET` (`0.60`), `round4(value)`, `clamp_vector(vector)`, `evaluate_thermodynamics(vector)`, `validate_and_balance_thermodynamics(vector, free_sandbox_mode)`.
- `[hex_math.gd:HexMath]` — `HEX_SIZE` (`240.0`), `DIRECTIONS`, `make_id(q, r)`, `parse_id(hex_id)`, `hex_distance(q1, r1, q2, r2)`, `get_neighbor_ids(q, r, valid_cells)`, `get_brush_hex_ids(center_id, radius, valid_cells)`, `generate_hex_spiral(radius)`, `axial_to_world(q, r, hex_size)`, `compute_village_sector_offset(index, total_count, hex_size)`.
- `[catalog.gd:EvoCatalog]` — `PRESET_IDS`, `DEFAULT_STRATEGY_A_ID`, `DEFAULT_STRATEGY_B_ID`, `create_base_traits_catalog(lang)`, `create_base_decisions_catalog(lang)`, `create_base_strategies_catalog(lang)`, `compute_strategy_vector(strategy, traits_catalog)`, `compute_deme_vector(deme, traits_catalog)`, `deme_has_trait(deme, trait_id)`, `compute_baseline_decision_weights(deme, traits_catalog)`, `compute_strategy_baseline_probabilities(deme, traits_catalog)`, `apply_strategy_to_deme(state, deme, strategy_id, lang)`, `deme_has_cultural_capacity(deme, traits_catalog)`, `inject_trait_into_deme(state, deme_id, trait_id, lang)`, `create_preset_world(preset_id, lang, strategy_a_id, strategy_b_id)`.
- `[presets.gd:EvoPresets]` — `create_preset_world(preset_id, lang, strategy_a_id, strategy_b_id)`, `_build_darwin_archipelago(state, lang, is_en)`, `_build_finite_island(state, lang, is_en)`, `_build_rift_savanna(state, lang, is_en)`.
- `[i18n.gd:EvoI18n]` — `STRINGS`, `TRANSLATIONS`, `resolve_lang(lang)`, `t(lang, key, params)`, `ui(key, lang, params)`, `strategy_text(strategy_id, field, fallback, lang)`, `strategy_name(lang, strat_def)`, `strategy_description(lang, strat_def)`, `trait_text(trait_id, field, fallback, lang)`, `decision_text(decision_id, field, fallback, lang)`, `localize_world_state(state, lang)`, `biome_name(lang, biome)`, `trait_name(lang, trait_def)`, `trait_description(lang, trait_def)`, `decision_name(lang, dec_def)`, `decision_description(lang, dec_def)`, `archetype_name(lang, archetype)`, `status_name(lang, status)`, `village_tier_name(lang, tier)`, `preset_title(lang, preset_id)`, `preset_description(lang, preset_id)`, `preset_hypothesis(lang, preset_id)`, `chronicle_type_name(lang, event_type)`.
- `[user_settings.gd:EvoUserSettings]` — `DEFAULT_PRIMARY_MODEL` (`"d3:4b"`), `DEFAULT_SECONDARY_MODEL` (`"tev1:4b"`), `DEFAULT_CONTEXT_LENGTH` (`8192`), `primary_model`, `secondary_model`, `context_length`, `config_path_override`, `get_config_dir()`, `get_config_path()`, `load_settings()`, `save_settings()`, `get_user_catalog_path()`, `save_user_catalog(state)`, `load_user_catalog_into(state)`.

## Invariants
- `[thermodynamics.gd:clamp_vector]` — Every `BiophysicalVector` axis (`metabolic_cost`, `extraction_efficiency`, `ecological_impact`, `spatial_mobility`, `social_cohesion`) is clamped to `[-1.0, 1.0]` and `transmission_threshold` is clamped to `[0.0, 1.0]`, snapped to `0.0001` via `[thermodynamics.gd:round4]`.
- `[thermodynamics.gd:evaluate_thermodynamics]` — Thermodynamic conservation requires `positive_advantages <= BASE_BUDGET` (`0.60`) or `current_cost >= 0.5 * (positive_advantages - BASE_BUDGET) - 0.000001`, where `current_cost = metabolic_cost - min(0.0, ecological_impact)`; `[thermodynamics.gd:validate_and_balance_thermodynamics]` adjusts `metabolic_cost` and `ecological_impact` to restore balance unless `free_sandbox_mode` is `true`.
- `[catalog.gd:deme_has_cultural_capacity]` — Cultural traits (`category == "cultural"`) and cultural decisions (`dec-exchange-symbiosis`, `dec-explore-innovate`) require at least one biological trait with `enables_cultural_transmission == true` (`bio-encephalization` or `bio-social-instinct`); `[catalog.gd:apply_strategy_to_deme]` and `[catalog.gd:inject_trait_into_deme]` strip or reject cultural traits when this requirement is unmet.
- `[catalog.gd:inject_trait_into_deme]` — Enforces bidirectional mutual exclusion via `TraitDef.mutually_exclusive_with` (e.g., `bio-r-strategy` vs. `bio-k-strategy`) before adding a trait and synchronizes `LineageNode` trait lists.
- `[types.gd:EvoTypes]` — `HexCell` enforces at most 1 resident deme (`deme_ids.size() <= 1`), tracks rural hinterland ownership (`land_use` in `"wild" | "crops" | "pasture"`, `owner_deme_id`) and persistent `has_ruins`; `Deme` tracks `salubrity` (`[0.05, 1.0]`), `walled_union_id`, and a strict 4-tier settlement scale (`get_village_tier()` in `1..4`, `get_village_roman()` in `"I".."IV"`).
- `[types.gd:make_pair_key]` — `WorldState.active_pacts` keys are lexicographically ordered (`id_a + "__" + id_b` with `id_a < id_b`); values `>= 2` indicate an active formal pact (`[types.gd:is_pact_active]`) and values `< 0` indicate an active vendetta (`[types.gd:is_vendetta_active]`).
- `[presets.gd:_make_cell]` — `HexCell` coordinates satisfy the cube coordinate constraint `s = -q - r` and string IDs match `"%d,%d" % [q, r]` (`[hex_math.gd:make_id]`). All preset worlds initialize at `map_radius = 7` (`169` hex cells) with `deme_ids.size() <= 1`.

## Side Effects
- `[user_settings.gd:load_settings]` / `[user_settings.gd:save_settings]` — Reads and writes `~/.config/Evolution/settings.json` (or `config_path_override`) on disk via `FileAccess` and `DirAccess.make_dir_recursive_absolute`, mutating static fields `primary_model`, `secondary_model`, and `context_length`.
- `[user_settings.gd:save_user_catalog]` / `[user_settings.gd:load_user_catalog_into]` — Writes and reads `~/.config/Evolution/user_catalog.json` on disk to persist and restore `user`/`custom`-origin strategies, traits, and decisions into `WorldState`.
- `[hex_math.gd:get_neighbor_ids]` — Populates static memoization cache `_neighbor_caches_by_size` keyed by `valid_cells.size()` and coordinate hash `(q + 16) * 32 + (r + 16)` (supporting `map_radius <= 15` with zero collisions); `compute_village_sector_offset` returns `Vector2.ZERO`.
- `[catalog.gd:apply_strategy_to_deme]`, `[catalog.gd:inject_trait_into_deme]`, `[presets.gd:create_preset_world]`, and `[i18n.gd:localize_world_state]` — Mutate `WorldState`, `Deme`, and `LineageNode` instances in place, clear cached metadata (`compact_str`, `compact_criterion`, `dec_cat_hash`), and trigger `EvoDecisionModel` evaluations.
